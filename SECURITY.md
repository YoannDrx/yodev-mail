# Security policy

## Supported version

YoDevMail is currently in private beta preparation. Only the latest commit on
`main` is supported; no public production release is supported yet.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability and do not include
credentials, email addresses, message content or customer data in a report.

Use GitHub's private vulnerability reporting flow:

https://github.com/YoannDrx/yodev-mail/security/advisories/new

Include the affected route or component, a minimal reproduction without real
personal data, the expected impact and any suggested remediation. We will
acknowledge receipt within five business days and coordinate disclosure after a
fix is available.

## Scope

Reports about authentication, workspace isolation, transactional email
acceptance, provider credentials, billing, webhooks, attachments and
infrastructure permissions are in scope. Marketing, newsletter, cold-email and
campaign features are not part of YoDevMail.
